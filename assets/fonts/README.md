# Bundled fonts

Unmodified official static TTFs. Each family retains its full OFL copyright and license beside these files.

Inter source: https://github.com/rsms/inter/releases/download/v4.1/Inter-4.1.zip, `extras/ttf/`.

Manrope source: https://github.com/googlefonts/manrope/tree/master/fonts/ttf. Upstream names are `manrope-regular.ttf`, `manrope-medium.ttf`, `manrope-semibold.ttf`, and `manrope-bold.ttf`. Local filename capitalization is normalized; font bytes are unchanged.
